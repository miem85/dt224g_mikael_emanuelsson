## Git

Jag har använt Git och GitHub för versionshantering. Jag skapade branchen `features`, gjorde ändringar där och mergade sedan tillbaka till `main`.

### git add och git commit

`git add` väljer vilka ändringar som ska sparas. `git commit` sparar ändringarna med ett meddelande.

### Branches

Branches används för att kunna göra och testa ändringar utan att påverka `main`.

### Merge

En merge lägger ihop ändringarna från en branch med en annan. Jag mergade `features` till `main`.

### GitHub och Netlify

GitHub används för att lagra koden och versionshistoriken. Netlify används för att publicera hemsidan på internet.

### Exkludera filer

I `.gitignore` kan man ange sådant som inte ska versionshanteras, till exempel känslig information, vissa filer, `node_modules` och loggfiler.
